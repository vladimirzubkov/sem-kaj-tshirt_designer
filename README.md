# T-Shirt Designer: Semestrální práce pro B0B39KAJ

## Téma: návrh grafiky pro trička online

### Popis nápadu projektu

**Popis:** Vytvořit webovou stránku pro online návrh trička s možností:

- Nahrávání SVG a rastrových obrázků.
- Základní kreslení.
- Vkládání textu.
- Uložení stavu a pokračování v práci.
- odeslání nebo stažení výsledku.

**Rozhraní:** Plátno vlevo, 3D model trička vpravo, menu s nástroji dole.

**Nástroje:** Text, výběr barvy, štětec, tužka, guma, voda.

**Proces:** Kreslíme na plátno, poté přeneseme na tričko pomocí nástroje:

- Válec: Přenos 1:1.
- Rozprašovač: Lehké míchání.
- Šejkr: Silné míchání.
- Šreddr: Male kousky v podobě aplikace. 

**Výstup:** Stáhnout PDF nebo odeslat e-mailem.
